01 — THE FOUNDATION

What is Abstraction?

Abstraction is an OOP principle that hides implementation details and exposes only the essential functionality to the user.

01

Hides complexity

Users can work with an object without knowing all the internal steps that make it function.

02

Shows essential features

Only the relevant operations are exposed through a simple interface.

03

Improves design

It helps separate what an object does from how it performs that task.

✦

Real-world example: ATM

You select Withdraw and enter an amount. You do not need to understand the ATM's internal banking operations. The machine exposes a simple operation and hides much of its implementation.

02 — THE APPROACHES

Types of Abstraction in Java

A ABSTRACT CLASS

Abstract Class

A class declared with the abstract keyword. It can contain abstract methods and implemented methods. 

abstract class Shape {
    abstract void draw();

    void info() {
        System.out.println("A shape");
    }
}

Useful when related classes share common state or behavior.

I INTERFACE

Interface

An interface defines a contract that implementing classes agree to follow. It can also contain default, static, and private methods. 

interface Payment {
    void pay(double amount);
}

class UpiPayment
        implements Payment {
    public void pay(double amount) {
        System.out.println("Paid");
    }
}

Useful for defining capabilities that different classes can implement.

03 — LEARN BY EXAMPLE

Java Abstraction in Action

A vehicle provides a common contract. Each specific vehicle decides how to start its engine.

AbstractionDemo.java 
abstract class Vehicle {

    abstract void start();

    void stop() {
        System.out.println("Vehicle stopped.");
    }
}

class Car extends Vehicle {

    @Override
    void start() {
        System.out.println("Car starts with a key.");
    }
}

class Bike extends Vehicle {

    @Override
    void start() {
        System.out.println("Bike starts with a button.");
    }
}

public class AbstractionDemo {
    public static void main(String[] args) {
        Vehicle car = new Car();
        Vehicle bike = new Bike();

        car.start();
        bike.start();
        car.stop();
    }
}
STEP 01

Declare

abstract class Vehicle creates a base class that cannot be instantiated directly.

STEP 02

Define

abstract void start(); declares what must happen without specifying how.

STEP 03

Implement

Car and Bike provide their own implementations of the start() method.

Expected console output 
Car starts with a key.
Bike starts with a button.
Vehicle stopped.

04 — KNOW THE DIFFERENCE

Abstract Class vs Interface

Feature Abstract class Interface
Keyword abstract class interface
Methods Abstract and concrete Abstract, default, static and private methods
Fields Instance and static fields Constants (public static final)
Inheritance A class extends one class A class can implement multiple interfaces
Constructor Can have a constructor Cannot have a constructor
